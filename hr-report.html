Сравнение оценок сотрудников по стажу. Группы отображаются только при наличии не менее 5 ответов.

Аналитика текучести

Отдельный импорт кадровой выгрузки — не смешивается с анонимными ответами опроса. CSV должен содержать столбцы: department, position, hire_date, exit_date, exit_type, reason. Даты — YYYY-MM-DD. Не добавляйте имена, телефоны и другие персональные данные.

Загрузите CSV с уволенными сотрудниками, чтобы рассчитать стаж до ухода и причины увольнения.

Качество кадровых данных

Проверка заполненности полей и дат. Строки с неполными данными не удаляются автоматически; некорректные даты исключаются из расчётов стажа и увольнений.

После импорта здесь появится проверка данных.

Динамика увольнений по месяцам

Количество увольнений по месяцу даты ухода. Для сравнения показателей текучести нужна численность сотрудников за каждый период.

Численность сотрудников по месяцам

Загрузите CSV с колонками month, headcount_start, headcount_end для общей численности компании. Для сравнения текучести по отделам добавьте столбец department и укажите численность каждого отдела отдельно по месяцам. Можно загрузить только отделы или общую численность. Коэффициент = увольнения за месяц / средняя численность за месяц × 100. Данные только по численности, без имён.

Численность не загружена. Коэффициент текучести пока не рассчитывается.
