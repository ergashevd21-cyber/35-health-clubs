Голос команды — аналитика

Сводный отчёт по ответам сотрудников. Загрузите экспорт из Supabase. Данные обрабатываются только в этом браузере и не отправляются на сайт.

Конфиденциальность: выгружайте данные только с разрешённым доступом. Не загружайте файл на общий компьютер. Дашборд не отправляет исходные ответы на сервер и не показывает отдельные комментарии, только тематические счётчики.

Загрузить ответы

Формат JSON (массив строк таблицы с полями answers, submitted_at) или CSV. В Supabase откройте Table Editor → survey_responses → Export.

Вход в HR-аналитику

Для просмотра отчётов войдите в одобренную учётную запись.

Негативные оценки

«Плохо», «Нет» или 0–6 на числовой шкале. Пропущенные ответы не входят в расчёт.

Распределение ответов

Темы комментариев

Автоматическая группировка по ключевым словам; это ориентир, а не точный анализ смысла.

Рекомендации HR

Гипотезы для проверки, не автоматические решения.
